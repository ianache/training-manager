# gf-icon

Material icon wrapper component.

## Usage

```typescript
<gf-icon name="check" label="Success" />
<gf-icon name="error" decorative="true" />
```

## Inputs
- `name`: Material icon name
- `label`: ARIA label (for non-decorative icons)
- `decorative`: if true, sets aria-hidden

## Accessibility
- ✅ Supports ARIA labels
- ✅ Marks decorative icons with aria-hidden
