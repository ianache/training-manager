# Evidencia requerida

- **ID:** TRM-0099
- **Tipo:** término
- **Sinónimos:** —
- **Definición:** Requisito de evidencia de una competencia y nivel que se debe satisfacer siempre: para certificar ese nivel el colaborador debe presentar todas las evidencias requeridas.
- **Ámbito:** Plataforma de Gestión de Formación

- **Notas:** Es uno de los dos valores con que se declara cada requisito de evidencia (BRC-001 BR-ACR-12, decisión de ianache (Jefe de Ingeniería), 2026-09-27, en respuesta a P-23); el otro es la [evidencia deseada](TRM-0100-evidencia-deseada.md). Lo define el Jefe de Ingeniería (BR-CAT-16, /knowledge-base/business/rules/BRC-001-reglas-plataforma-gestion-formacion.md:L160), de donde se toma el responsable. Si el evaluador puede aceptar una evidencia equivalente a la requerida sigue abierto (P-23). Un nivel que aún no tiene requisitos definidos no se puede certificar (BR-ACR-13, respuesta a P-39, 2026-09-27); que deba tener al menos una evidencia requerida es una inferencia a confirmar (BR-ACR-13).
