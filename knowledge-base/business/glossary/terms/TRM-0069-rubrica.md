# Rúbrica

- **ID:** TRM-0069
- **Tipo:** concepto
- **Sinónimos:** —
- **Definición:** Descripción asociada a una competencia que, para cada nivel de L1 a L4, define cómo se evidencia la competencia: lo que se espera que el colaborador evidencie para certificarlo en ese nivel.
- **Ámbito:** Plataforma de Gestión de Formación
- **Fuentes:**

- **Clasificación:** decision
- **Confianza:** high
- **Responsable:** Jefe de Ingeniería
- **Relacionados:** [Competencia](TRM-0014-competencia.md) · [Escala de niveles de dominio](TRM-0020-escala-de-niveles-de-dominio.md) · [Requisito de evidencia](TRM-0068-requisito-de-evidencia.md) · [Certificación](TRM-0001-acreditacion.md)
- **Notas:** Hay una por competencia (BRC-001 BR-CAT-15, decisión del 2026-09-26). Si contiene los requisitos de evidencia, y quién la define y aprueba, está abierto (P-37). Se usa "certificar" para las competencias de la persona (BRC-001 BR-TER-01).
