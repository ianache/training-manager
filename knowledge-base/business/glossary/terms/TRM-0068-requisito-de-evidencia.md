# Requisito de evidencia

- **ID:** TRM-0068
- **Tipo:** concepto
- **Sinónimos:** —
- **Definición:** Lo que un colaborador debe cumplir para certificar un determinado nivel de una competencia en el rol que tiene asignado: una o varias evidencias concretas (un curso, una práctica o un entregable), cada una de una de las tres categorías y declarada como requerida o deseada; certificar el nivel exige presentar todas las requeridas. Lo define el Jefe de Ingeniería.
- **Ámbito:** Plataforma de Gestión de Formación

- **Notas:** Incorporado por decisión de ianache (Jefe de Ingeniería), 2026-09-26 (IMD-001 IM-Q5). Si el requisito varía según el rol está abierto (P-34; BRC-001 AMB-05). No confundir con la evidencia: el requisito dice qué se exige (por ejemplo, un plan de pruebas) y la evidencia es lo que se presenta (el plan de pruebas de un sprint de un proyecto real) (BR-ACR-11). Relación con la [rúbrica](TRM-0069-rubrica.md) de la competencia: desde el 2026-09-27 la rúbrica describe el comportamiento y el logro visible y verificable, que se verifica con evidencias (BR-CAT-15, respuesta a P-37); BRC-001 P-37 infiere, a confirmar, que son cosas distintas: el requisito dice con qué evidencia se verifica lo que la rúbrica describe. Se usa "certificar" para las competencias de la persona (BRC-001 BR-TER-01). Definición revisada el 2026-09-27 por decisión de ianache (Jefe de Ingeniería): lo define el Jefe de Ingeniería, responsable de las capacitaciones (BR-CAT-16, respuesta a P-21); se confirma que es una evidencia concreta de una de las tres categorías (EVD-2026-0097, P-22); cada requisito se declara [requerida](TRM-0099-evidencia-requerida.md) o [deseada](TRM-0100-evidencia-deseada.md) y ya no son "todas obligatorias" (BR-ACR-09, BR-ACR-12, P-23). Su definición es progresiva: no hace falta definir todos los niveles de todas las competencias a la vez (BR-CAT-17, /knowledge-base/business/rules/BRC-001-reglas-plataforma-gestion-formacion.md:L161, P-24). Un nivel sin requisitos definidos no se certifica ni se exige en un Rol-Nivel o requerimiento (BR-ACR-13, respuesta a P-39 de ianache (Jefe de Ingeniería), 2026-09-27, EVD-2026-0114); que al menos uno deba ser requerido es una inferencia a confirmar; si el evaluador puede aceptar una evidencia equivalente sigue abierto (P-23).
