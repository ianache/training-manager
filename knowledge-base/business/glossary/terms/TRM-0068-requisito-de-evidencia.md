# Requisito de evidencia

- **ID:** TRM-0068
- **Tipo:** concepto
- **Sinónimos:** —
- **Definición:** Lo que un colaborador debe cumplir para certificar un determinado nivel de una competencia en el rol que tiene asignado: una o varias evidencias concretas (un curso, una práctica o un entregable), cada una de una de las tres categorías, y todas obligatorias.
- **Ámbito:** Plataforma de Gestión de Formación

- **Notas:** Incorporado por decisión de ianache (Jefe de Ingeniería), 2026-09-26 (IMD-001 IM-Q5). Si el requisito varía según el rol está abierto (P-34; BRC-001 AMB-05). No confundir con la evidencia: el requisito dice qué se exige (por ejemplo, un plan de pruebas) y la evidencia es lo que se presenta (el plan de pruebas de un sprint de un proyecto real) (BR-ACR-11). Relación con la [rúbrica](TRM-0069-rubrica.md) de la competencia: probablemente la rúbrica contiene los requisitos de cada nivel, pero está abierto (P-37). Se usa "certificar" para las competencias de la persona (BRC-001 BR-TER-01).
